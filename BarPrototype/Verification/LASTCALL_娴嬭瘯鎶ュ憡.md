- 最终在线模拟：23 次实际网关请求，28,455 token，终态仍为 online，未更换模型。
- 离线模拟：0 次模型请求，正常闭店。
- 另一次网关故障模拟在 5 次请求后明确降级离线，仍完成整晚并成功恢复存档。

证据：lastcall-online-night.json、lastcall-offline-night.json、lastcall-degraded-night.json。
这里加速了服务端时钟，并沿导出的网格确认移动，不冒充真实 3D 操作或 12 分钟实时窗口测试。

## 本轮发现并修正

- 本机系统代理曾把 loopback HTTP 转成 502；现只让本地连接绕过代理，不改系统代理。
- 空 WebSocket 状态在 Unity JSON 解析中被当作游戏；现检查有效 sessionId。
- 局部镜头视口留下旧 UI 残影；现使用全窗口背景清屏。
- 安静角落坐标落在封闭卡座内；改到可到达区域并重新导出网格。
- 路点在异步更新中被重复追赶；现按路径版本记录客户端已走过的路点。
- 逐角色位置包积压会拖延暂停和交互；现合并最新位置批次，并优先发送操作命令。
- 重连补回完整可见历史，并按事件 ID 合并；不会只保留断线前后的 45 条。
- 反复评估同一旧事件浪费模型额度；已记录处理历史并限制延迟重评。

## 交付与边界

运行包包含游戏、Node 运行时、后端和依赖，不需要用户安装开发工具。
打包时排除 DoNotShip 调试目录。密钥与存档位于 LOCALAPPDATA/LALAGAME，不随包交付。
隐私扫描未发现密钥文本或数据库进入源码 / 运行包；不包含私人附件、真实聊天或用户照片。

这是首版低多边形 MVP：程序化动画、规则保底和有限的社交行动，不是无限剧情系统。
未逐一人工走遍所有家具缝隙、所有输入法和所有 C/D 分支，也未做长时间压力 / 多设备性能认证。
