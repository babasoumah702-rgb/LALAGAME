# LA LA LAND · 整晚版

解压整个文件夹，运行 `LastCall.exe`。不要单独移动 exe；`LastCall_Data`、`MonoBleedingEdge` 和 `Server` 必须留在旁边。

## 操作与流程

WASD / 方向键移动，右键拖动视角，E 选择附近的人。可以观察、走近、交流，也可以只旁观。输入文字时暂停世界时间。暂停菜单可存档、继续，或明确切换离线规则模式。

新局从电梯开始，依次经过第三杯、动态社交、塔罗、走廊、夜深散场和屋顶。D 只在第三杯章节末尾到场一次。塔罗可以跳过、不参加；走廊可以不跟；断电后可沿楼梯上楼，也可留下或离开。屋顶的“确认结束”才会结束这一晚。

NPC 对白显示在头顶；玩家发言显示在下方。气泡可能因角色离屏或遮挡而隐藏，线索册保留已经实际感知的内容。主观回忆不等于玩家角色知道的事实，可按空格跳过。

## 在线模型

在游戏首页点击“填写模型 API”或“模型 API · 已配置”，填写：

- 接口地址：OpenAI 兼容接口的根地址，程序会在末尾调用 `/chat/completions`。例如 DeepSeek 填 `https://api.deepseek.com`，OpenAI 填 `https://api.openai.com/v1`。
- 模型名称：该接口实际支持的模型 ID。
- API Key：玩家自己的密钥。已经保存过时，留空再次保存会保留原密钥；也可以在同一页清除。

配置保存到当前 Windows 用户的 `%USERPROFILE%\.lalagame\private\model.env`，不放进游戏目录、ZIP、存档或日志，前端也不会回显已经保存的密钥。该本地文件不是加密保险库，建议使用有限额、可撤销的独立密钥，不要在公共电脑保存。

远程接口必须使用 HTTPS；只有本机 `localhost`、`127.0.0.1` 或 `::1` 可以使用 HTTP。接口还需要兼容 `response_format: json_object`。不同供应商的余额、地区、限流和模型权限由玩家自己的账号承担。

没有密钥、连接失败、超时、鉴权或校验失败时，会显示可重试提示，不用固定台词替角色发言。只有手动选择“离线规则”后才使用规则回复。

每章最多 80 次模型调用、120000 token；电梯邀约计入第一章，共六份预算。读档和重试不重置预算。每次重新生成也消耗预算。界面和线索册区分 AI、离线规则、场景内容、玩家原话和旧记录的未知来源。

本机服务仅监听回环地址。在线模式会把当前角色需要的合成游戏上下文发给所配置的模型服务；本版不录音、不做语音识别、不生成角色配音。

## 存档兼容

存档放在系统本地应用数据目录的 LALAGAME 下，不随运行包分发。已有章节存档保留进度、预算与已发生事件；没有章节数据的旧局继续旧流程，不插入新剧情。想体验整晚流程请开新局。

实际验收范围、限制与来源记录见同目录的 `FULLNIGHT_测试与来源说明.md`。ZIP 的 SHA-256 在压缩包旁的 `.sha256` 文件中。
