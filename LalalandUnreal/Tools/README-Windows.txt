LALALAND — Unreal Engine 5.8 Scene 0–1 竖切片

启动
1. 双击本目录的 Lalaland.exe。
2. 首次进入依次选择身份、目的和聊天方式。
3. 如需在线 AI 对话，在入口的“模型 API”区域填写兼容 OpenAI 接口的地址、模型 ID 和 API Key。

操作
- W / A / S / D：移动
- 按住鼠标右键：转动视角
- Esc：暂停或继续
- 游戏内剧情入口固定为“观察 / 移动 / 互动”。

隐私
- API Key 只发送给本机随游戏启动的叙事服务。
- API Key 不写入 Unreal 存档、游戏资源或普通运行日志。
- 本包不包含开发者密钥、开发存档或开发日志。

当前内容
- 三页新游戏入口
- 电梯 Scene 0
- 第三杯、定向 AI 对话、D 入场与 Scene 2 就绪点
- A–D 原始模型及内嵌身体动画

已知限制
- 当前是 Scene 0–1 虚幻竖切片，并非 Scene 0–6 完整迁移版。
- Windows 上本地 WebSocket 握手失败时会自动切换到认证 HTTP 兼容通道，剧情和输入不会因此冻结。
- A–D 原模型没有面部 BlendShape，因此本版没有口型和面部表情。
