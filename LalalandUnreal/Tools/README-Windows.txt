LALALAND — 酒吧首夜 体验版（Unreal Engine 5.8）

启动
1. 双击本目录的 Lalaland.exe。
2. 如需在线 AI 对话，先填写兼容 OpenAI 的接口地址、模型 ID 和 API Key，再点「使用在线 AI 开始新夜晚」。不填写时必须明确点「使用离线规则开始」。
3. 电梯门开后进入顶楼酒吧。

操作
- W / A / S / D：移动
- 按住鼠标右键：转动视角
- 靠近并看向一个人，即可自由输入对话；按 Enter 或点「发送」
- 屏幕下方最多三个情境按钮（捡球、酒单、弹球、邀约等）
- Esc：暂停
- 「微醺视效」：降低或关闭醉意画面

今晚可以做什么
- 和 Kiko、X、万塞、一桐四位刚认识的人说话
- 用 Cash 点酒、请客；对方可以接受或拒绝；喝下后才会有微醺
- 参加或旁观弹球入杯（球必须先落桌再进杯）
- 赛后选歌、活动或特调券
- 流星雨时邀请一人上露台，或自己上去
- 结束时看到基于亲见事件的结算；攀岩馆和温泉尚未开放
- BGM 随弹球、选歌、流星雨与露台阶段变化；酒杯、门、电梯和手机有事件音效

隐私
- API Key 只发送给本机随游戏启动的叙事服务。
- API Key 不写入 Unreal 存档、游戏资源或普通运行日志。
- 本包不包含开发者密钥、开发存档或开发日志。

已知限制
- 这是酒吧首夜体验版，不是城市、温泉、攀岩或案件线。
- 酒单是固定特调，没有自由调酒。
- Windows 版使用本机认证 HTTP 同步状态（约 5 次/秒），不会受系统代理或 WebSocket 握手影响。
- 角色没有口型和面部表情。
- B（X）、C（万塞）、D（一桐）已使用新版人物模型；动作由 Unreal IK Retargeter 从现有动作库重定向。
