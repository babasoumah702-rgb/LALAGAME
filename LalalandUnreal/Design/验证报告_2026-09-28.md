# Lalaland Unreal 新模型、A2A 与 Windows 验证报告

## 本轮内容

- A 保留既有模型。
- B 使用 `female+character+3d+model（X）.zip`。
- C 使用 `human+character+3d+model(万塞）.zip`。
- D 使用 `anime+schoolgirl+3d+model （一桐）.zip`。
- 新 FBX 的 61 骨骼与旧角色的 41 骨骼不兼容，因此没有强制复用旧 Skeleton。导入工具为每人建立独立 Skeleton、IK Rig 和 IK Retargeter，再生成与目标 Skeleton 匹配的动作。

## 已知限制

- 新模型没有可用的面部 BlendShape，本轮没有口型和面部表情。
- C、D 原始 FBX 不含可直接使用的动作片段，当前动作来自项目既有动作库的 IK 重定向。
- 新 FBX 在 Cook 时报告少量零长度切线／法线提示；本轮可见窗口未发现骨骼塌陷或脚底下沉，但后续制作近景镜头时仍应复查材质接缝和手指细节。
- 首次在开发环境导入或 Cook 新模型会生成贴图、蒙皮和动画缓存；16GB 内存机器会比后续启动慢。
- 角色仍可能在幅度较大的旧动作中出现手部贴近桌面的轻微穿插，后续应针对桌边动作制作姿态修正层。
