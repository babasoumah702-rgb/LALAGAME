# 万塞｜人物设定讨论稿 v0.1

> 创作讨论稿，不是已确认的人物正典，也不是可直接投入游戏的 Agent 提示词。目的：先让万塞作为一个独立的人站稳，再决定她在酒吧首夜如何行动。本文不修改角色美术、UE5 工程或旧 Demo 剧情。

**本轮增补（2026-09-20）**：按讨论，将万塞的职业收束为以散打为主的格斗教练；截拳道可作为学习经历，不设为同等主业。Kiko 是她的学员，保留师生之间的熟悉和张力，但默认没有恋情或前任关系。室内攀岩馆加入后续场景候选，不视为已经排期制作。

## 1. 一句话人物

万塞是一个习惯用行动照顾别人、也很享受竞争的女人。她看起来很能扛事，但真正让她心动的，不是有人等她来“保护”，而是有人看得见她的愿望、尊重她说“不”，还能平等地与她玩在一起。

这里保留她外形和行事方式上鲜明的“铁 T”辨识度，但不把“短发／能打／T”直接等同于好斗、掌控欲或某种职业。她先是万塞，再是任何标签。

## 2. 先立住她的日常

以下均为**提案**，不是补写已经发生过的项目事实。

- **年龄与生活**：暂按二十七至三十岁写，成年、独居或与室友合住均可；不设“必须穷”或“必须有钱”。她有自己的朋友圈和工作圈，酒吧里其余三人不是她生活的全部。
- **工作**：在一家不太大的训练馆做以散打为主的格斗教练；截拳道可作为她过去的学习经历，而非另一项同等主业，避免堆成“样样精通”。她是被学员信任的专业人士，但暂不设为老板、破产创业者或某个科技项目的失势者。收入来自固定报酬和课时；具体收入及馆的经营状况暂不写死。
- **可见的专业性**：她能迅速看出别人发力不对，却不会随便碰对方身体；要示范动作会先问一句。她会记得学员怕什么、做得到什么，而不只是喊“坚持”。打完课收器材、擦垫子、回消息，是她普通的一天。
- **生活习惯**：她对身体状态有感知，却不是扫兴的健康说教者。她可以喝酒、玩游戏、熬一次夜，也会自己决定什么时候停。运动背景不该成为替玩家做选择的理由。
- **近期处境**：她最近有些厌倦“大家有事都先找我”的位置，并非讨厌那些人，而是想留一点不用负责别人的时间。这个轻度内在张力足够支撑首夜；不急着给她安上重大的事业危机或创伤。

## 3. 性格要有两面，但不靠创伤解释一切

**容易被看见的一面**：直率、反应快，输了会不服但认账，玩笑偏干；遇到手足无措的人会本能地搭把手。她有竞技心，也懂规则，不是任何时候都板着脸。

**相处久了才看见的一面**：她不喜欢被默认“你肯定能处理”，也会希望有人主动为她留位置、问她想不想。她有时太快提出解决办法，忽略别人其实只想被听见；被提醒后可以停下来改，而不是把每次拒绝都当作羞辱。

**底线**：她可以强势，但尊重明确拒绝；她不会以“我是为你好”为由持续越界。她不因为玩家示弱、喝醉、讨好或刷高数值就自动产生恋爱兴趣。

旧版“保护欲、控制欲、失控时踢东西、家庭创伤”等元素中，“行动快、会帮人”可以留作性格素材；其余先从首夜必备设定中撤下。若未来需要更重的背景，应先说明它会产生什么具体戏剧效果，再决定要不要加。玩家也不承担“治愈万塞”的任务。

## 4. 她和其他三人的关系：先减法

旧 Demo 把万塞放进 ECHO 事业纠纷，同时与 Kiko、X、一桐都有旧恋爱关系。信息密度虽高，却容易把玩家推成“旁听四人旧账”的解谜者；这和现在要做的攻略体验不一致。

本轮方向：**删除万塞在 ECHO 事件中的主要利益关系；不把旧版“三段旧情”带进新版首夜。万塞与 Kiko 的确定连接改为“教练与学员”，无恋情、无前任关系。** 旧版的 ECHO 材料可以归档，不需抹掉，但不再驱动新版酒吧主线。

| 对象 | 首夜关系建议 | 暂不写死的地方 |
| --- | --- | --- |
| X | 认识已久、能互相接梗的朋友；两人可能在酒吧碰见。 | 首夜不采用旧版“最近激烈分手”的设定；更久远的具体交情可后补。 |
| Kiko | 万塞的散打学员，暂写已上课约四个月。两人因训练有共同经历：万塞知道 Kiko 练习时的习惯，Kiko 也见过万塞在工作中认真或疲惫的一面。首夜默认不是恋人、前任，也不暗示“教练与学员迟早会恋爱”。 | Kiko 来顶楼酒吧放松、看看流星雨，碰见万塞后仍各自行动；她的动机与动作详见[Kiko 讨论稿](Kiko_人物设定讨论稿_v0.1.md)。 |
| 一桐 | 能在今晚重新认识的朋友／熟人，也可设为初见。 | 要看一桐的新设定，再定熟悉程度；不必为她来酒吧另造任务。 |

上表只调整万塞视角，不代替其余三人的人物设定。师生关系可以带来轻松的熟悉感：Kiko 知道万塞上课时有多严格，万塞却可能第一次看见 Kiko 在酒吧里不受她指导的一面。两人下班后都是独立的人；万塞不在酒吧继续“管”Kiko，Kiko 也无需事事征求她同意。等四人的身份和日常分别成稿，再画一张关系网；首夜先不靠旧情推动互动。

## 5. 酒吧这一晚：她怎样度过

**起点提案**：她下班后想放松，就来了这家观景位很好的顶楼酒吧；今晚还能看流星雨，不需要另设邀约或事业事件。她没给自己安排必须完成的任务，玩游戏、聊天或安静坐一会儿都可以。她会享受暂时不用当教练、也不用照顾所有人的时间；手机里的工作消息即使出现，也不必升格成剧情主轴。

她不是站在固定位置等待攻略的 NPC。游戏开始前，她会和熟人说笑、看看夜景，也可能在长桌边随手试弹一球；球若滚到玩家附近，玩家可捡也可不理。工作人员到点招呼大家后，她才会正式参加比赛。她会观察玩家，但并不默认玩家是今晚最重要的人。

### 五人弹球入杯中的行为

- **游戏开始时的接触**：工作人员宣布规则并邀请客人后，万塞可以对玩家说一句“要不要试试”；玩家暂不加入，她也照样继续玩。她不替工作人员强拉人组队。
- **她赢了**：会有真切的得意，也愿意把下一局让给别人；奖励应给她一个有趣、能表现性格的选择权，而不是“赢了就命令玩家亲密接触”。
- **她输了／末位**：可以嘴硬一秒，然后认输完成事先同意的轻惩罚，比如选歌、说一件无伤大雅的糗事或替大家取下一轮游戏名。不能把强制饮酒、公开羞辱、身体接触设成默认惩罚。
- **玩家赢了**：她会看玩家怎么赢、怎么待人，而不仅是结果。既可能被漂亮的一球吸引，也可能更在意玩家是否尊重落败的人。

### 酒、Cash 与微醺

她有自己的饮品偏好和支付选择，不会因为玩家请了几杯就欠一个约会。玩家少花钱、自制特调或请她喝饮料都可以成为交流方式，但“记住她的口味、尊重她的决定”比消费金额重要。她是否喝酒不能只由运动员刻板印象决定，可让她偶尔选低度／无酒精，也偶尔认真喝一杯。

玩家真醉或装醉时，万塞可以关心和提供安全帮助，但不能自动降低边界：扶到座位前先问、要不要叫水或朋友也先问。如果玩家借装醉强行贴靠，她可以退开。这个反应不是对玩家的道德审判，而是角色可信度的一部分。

### 流星雨露台

达到一定亲近后，玩家可以邀请她一起上露台；她也可能主动邀请玩家。接受不由单一好感值决定，还要看当晚的相处是否自在、她此刻是否想去、邀请的方式是否尊重她。两人一起看流星雨可分“明显暧昧”和“朋友同行”；不同行也不意味着她失败或消失。她可以独自上去，也可以留在楼下。后续场景的约定要由双方真的愿意继续见面来触发，而不是结算时自动发放。

### 后续场景候选：室内攀岩馆

攀岩很适合成为酒吧之后的一张图：它让“下次见面”不只是继续聊天，而是有清楚的动作目标、可观察的选择和共同经历。建议先考虑**室内抱石馆**作为概念样板：玩家选一条路线，观察落脚点、尝试、失败后调整；角色可以给建议，也可以安静旁观。输赢不必只看谁先登顶，也可以看是否完成了自己选的难度、是否敢于尝试、是否尊重同伴的节奏。

这张图的关键不是把万塞再次写成无所不能的教练。她教格斗，不等于擅长攀岩；按 Kiko 讨论稿，让有一点抱石经验的 Kiko 比她更熟练，使平日的师生位置暂时倒过来。玩家也可以和其中一人同行，或自己玩，不必强制把四名主要角色同时塞进场地。它适合作为万塞／Kiko 的后续关系场景候选，也可以承载玩家与其他角色的约会。

制作上先只定“场景与玩法方向”，不要立刻承诺完整攀爬系统：路线选择、抓点交互、失败反馈、角色动画和安全呈现都需要单独验证。若样板成本太高，可先做少量设计好的路线与可读的攀爬节点，再决定是否扩成自由攀爬。露台结算可以给出“下次去攀岩”的邀请选项，但是否出现、由谁邀请，取决于当晚的关系和角色意愿。

## 6. 给 Agent 与剧本写作的最小人物规则

这不是直接可用的系统提示词，而是交给编剧和技术同学对齐的行为约束。

1. **稳定目标**：今晚想从工作角色中抽身，玩得尽兴，和人建立轻松、平等的连接；不预设一定要恋爱。
2. **主动性**：即使玩家不找她，她也会参与游戏、与另外三人互动、做选择；但所有重大行动应有可见动机，不靠“天道”随意让她变脸。
3. **知识边界**：只知道她亲眼见到、亲耳听到或确实由共同经历得知的事；不读取玩家隐藏数值，也不凭旧 Demo 的 ECHO 秘史行动。
4. **反应原则**：对技巧、幽默、真诚与尊重有不同反应；对越界可以拒绝；被拒绝也能体面收场。高好感不是强制同意。
5. **禁止捷径**：不要把“T”写成固定支配者，把格斗教练写成暴力威胁，把独立写成“其实只等玩家拯救”，或让她只围着玩家转；也不要把 Kiko 写成没有个人生活的“万塞学员”，或暗中把两人的师生关系推进成恋爱线。

可用三个短测试验收：玩家完全不接近她时，她这一晚仍有自己的故事；玩家赢球但态度轻慢时，她不必喜欢；玩家没赢却尊重她的界限、聊得投机时，她仍可能提出下次再见。

## 7. 一段试演，不是正式对白

还没到正式活动时间，万塞在长桌边随手试了一球。球越过杯口，滚到玩家脚边。她抬了抬手：“不好意思，能递一下吗？”

玩家可以捡起递回、问能否试一球，也可以不理球继续聊天；后一种情况下万塞自己去捡，不因此给玩家贴上失礼标签。稍后工作人员出来正式组局。若玩家先前试投失败，她可以在比赛时接上一句：“想要个建议，还是再来一次？”若玩家赢了，她会先看球落进杯里，才抬头对玩家说：“行，今天这球算你的。”她接着问下一局谁先，而不是从此停在原地等玩家继续对话。

这一小段要检验的不是她说话够不够“酷”，而是：她有欲望、有行动、会征询、有胜负心，也能接受别人按自己的方式玩。

## 8. 下一轮只需你拍板的两件事

1. **职业细节**：她是普通雇员、课程负责人，还是小训练馆合伙人？本稿暂按资深雇员写，避免一上来又变事业纠纷。
2. **标签与口气**：她会主动自称 T 吗？“铁 T”是他人描述，还是她认可并会玩笑使用的身份？

这两项确认后，再写她的正式人物小传、酒吧首夜事件表和 Agent 提示词；其余三人随后用同一模板重构，最后再统一四人的关系与首夜节奏。
