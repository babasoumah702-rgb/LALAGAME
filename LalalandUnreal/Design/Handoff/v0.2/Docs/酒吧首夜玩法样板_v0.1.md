# LaLa-Land｜酒吧首夜玩法样板 v0.1

状态：创作讨论稿，2026-09-20；同日补充开局设计原则。用于统一创作方向和安排可玩样板，**不是**新版完整剧本、已实现功能清单或四位角色的最终设定。本文不改动旧 Demo 与 UE5 工程。

## 1. 这一晚究竟玩什么

玩家以第一人称进入顶楼酒吧，与 Kiko、X、万塞、一桐共同度过一晚。主要乐趣不是解开四人旧关系，而是主动认识、靠近并尝试攻略自己感兴趣的人；四位角色也会彼此交往、有自己的判断和主动行动，不会只等玩家点击。

这家酒吧本身就是很好的观景位，上方露台视野更开阔；今晚有流星雨。角色来这里可以只是想放松、喝点东西、看看夜景，不必人人带着邀约、任务或秘密事件。到了酒吧平时组织活动的时间，工作人员出来招呼客人、摆好道具、讲规则，才开始弹球局；它不必成为谁出门的理由。

本晚有一个清晰、可检验的目标：**在流星雨来临时，和一位愿意同行的人一起上楼到露台看星星。** 同行可以是浪漫方向，也可以是朋友；它表示“这一晚建立了真实的共同选择”，不表示恋爱关系自动成立。玩家也可独自上楼、作为旁观者上楼，或在邀请失败后直接结算。这些分支都有内容和下一站机会，但结算应区分“共同看星星已达成”与“本晚未达成”。

旧版“塔罗牌局”“关系真相解谜”“露台只作开放式快照”不自动继承为新版规则。可借用旧稿的空间调度、听见/看见的信息差与角色间自然互动，但不能直接套用旧对白、旧关系或旧 UI。

### 开局设计原则：先进入游戏，再通过行动定义自己

首轮样板以“一键开始新夜晚”为主路径。不给玩家先填职业、性格、攻略对象或自由背景，也不把“独自来 / 受邀来 / 参加活动”做成只有一句开场白不同的装饰性选择。开场只需交代玩家能做什么，并让第一项有后果的行动尽快发生。普通客人是系统默认的最低限度身份，不替玩家决定职业或性格。

玩家在场内可以通过说话、请客、参赛、靠近或保持距离逐渐呈现自己。自由发言首先是“玩家说过的话”，不能未经核实就升格为角色共同承认的世界事实；尤其不能一句自述就改写四位角色的既有记忆。若日后增加不同来历，必须为每种来历设计至少一处玩家能感到的行动或关系差异，再放进入口，而不是为了选项数量重做旧问卷。

### 开场三分钟候选：先选行为，不选身份

电梯门打开后，玩家先看见酒吧的夜景、吧台和各自在放松的四位角色。长桌旁可以有人在正式活动前随手试弹，一颗乒乓球滚到玩家附近：玩家能捡起递回、问一句怎么玩，也能不理它，继续和眼前的人聊天或去吧台。球只是一个可错过的小互动，不是比赛已经开始；到了活动时间，工作人员才出来正式招呼客人、说明规则和组织弹球局。

| 玩家的第一步 | 立刻获得的体验 | 随后可感到的差异 |
| --- | --- | --- |
| 捡起滚来的球，递回或随手试一下 | 获得一次自然的接触或操作机会 | 对方记得玩家曾接过这颗球；正式组局时可有一句接续回应 |
| 不理球，继续聊天或走向观景位 | 保持原本的社交或观景选择 | 球由旁人捡回，不把玩家未参与判成失礼或失败 |
| 去吧台 | 看见饮品与有限 Cash 的选择 | 调酒师或邻座记得玩家选了什么，赛后交谈可接上 |
| 直接走向某人 | 自己决定先认识谁 | 对方记得第一次接触方式；不需要先解开四人旧关系 |
| 暂时观察或走开 | 看见角色在没有玩家指挥时继续活动 | 有人之后自然招呼玩家；不把谨慎观察判成错误答案 |

球滚来可以发生在玩家刚入场时，也可以落在第一段聊天的自然空档；不要为了展示互动而打断一句正在说的话。各路之后都能听到工作人员到点招呼客人，并有机会加入五人游戏；首轮样板以玩家参与为主要可玩路径，具体如何处理暂不参加的人还需设计。无需制作多套独立章节，但“记得刚才的选择”必须至少落实为一句回应、一个可见动作或一个不同的互动机会；否则该选择只是旧 Demo 式的表面分叉，应删掉或重做。以上是可测试的开场方案，不是已定稿的角色演出。

## 2. 可玩的一晚：从入场到结算

| 阶段 | 玩家能做什么 | 世界如何回应 | 必须让玩家明白什么 |
| --- | --- | --- | --- |
| 入场与定向 | 一键进入酒吧，看看夜景，靠近四人之一或先去吧台；球滚来时可捡也可不理 | 四人有各自位置与正在进行的小动作；有人随手试弹，但正式游戏尚未开始 | 今晚可以认识人、请人喝酒；稍后有工作人员组织活动，流星雨时可去露台；不用先填写身份表 |
| 第一轮接近 | 交谈、旁听、点饮品或给人做特调，也可以暂不介入 | 角色根据自己的偏好、在场者和刚发生的事回应；角色之间也有少量可观察的互动 | 玩家行为会得到可读反馈，但不要求先弄懂四人的过往才能行动 |
| 工作人员组局 | 听活动招呼和规则介绍，决定是否参加 | 工作人员到点归拢道具、摆正式目标杯，邀请愿意玩的客人；四位角色按当晚状态回应，而非被剧情瞬间传送到桌边 | 先前的一两次随手试弹不是正式比赛；游戏有清楚的开始和玩法 |
| 五人弹球入杯 | 所有人从同一端轮流用乒乓球投向长桌另一端的杯子；玩家操作方向和力度 | 真正的球路与命中决定输赢；其他四人投球、观战、庆祝或失误，反应体现性格 | 玩家有机会靠操作赢、也可能输；输赢会打开不同互动，不直接决定谁喜欢玩家 |
| 赛后自由时间 | 领取赢家奖励或选择末位任务，继续聊天、请客、调饮品、接近想邀请的人 | 角色记得玩家如何赢/输、怎样对待别人；也可能主动接近玩家或与彼此互动 | 接近一个人需要共同经历与尊重边界，不能只刷单一好感值 |
| 流星雨与露台 | 尝试邀请一人、回应他人的邀请、与朋友同行、独自上楼，或提前结算 | 当晚的互动影响答复；流星雨提供机会窗口，不强迫角色同意 | 这是本晚目标选择，不是强制剧情传送门 |
| 结算与下一站 | 查看本晚结果与角色感受，选择已开放的后续场景或留待下次 | 给出所选角色基于亲见经历的简短评价/独白；保留未完成关系 | 有明确的本晚结果，同时不把一次拒绝写成永久失败 |

这是一条**流程骨架**，不是每个阶段都必须在固定分钟触发。玩家可以跳过部分社交、改变接近对象；角色在无玩家干预时仍做事。工作人员组织活动是酒吧日常的定时锚点，但应等当前对话自然收尾再招呼；流星雨也可以有时间窗口，不应在半句话中硬切事件。

## 3. 弹球入杯：第一版规则

- 一张长桌，远端先放一个目标杯；玩家和四位角色站在同一投球线。球必须在桌面弹跳后入杯，弹几次均可；出界、落地后再入杯不算。擦杯沿后入杯算命中。每次投球后重置球和杯。
- 五人轮流投，每轮每人一球。**首个命中者是赢家**，已经命中的人“上岸”；其余人继续，直到只剩一人尚未命中，该人是末位。命中先后决定名次，不按弹跳次数、动作好看程度或角色好感度计分。投球先后可逐轮轮换，减少站位优势。
- 为避免长时间无人投中，试玩时可在若干轮后缩短距离或放大杯口；具体轮数、球速、杯口和辅助瞄准须靠实测确定。若加赛仍多人未命中，允许“并列未上岸、无人受罚”，不随机指定一个输家。
- 玩家一回合只需完成“瞄准—控制力度—出手—看到球路与结果”。NPC 的投球也要在场景中看得见，并遵守同样的入杯判定；不能靠对白宣布某人突然赢了。
- 到活动时间，由酒吧工作人员临时主持、说明规则和彩头；可以由现有的调酒师或老板娘承担，不必为此新增重要角色。赢家从“特调券 / 下一首歌或下一项小活动的选择权”等轻奖励中选一项。末位从“调一杯无酒精特饮 / 回答轻松问题 / 帮大家选歌”等任务中选一项；若不愿做任务，样板可提供事前标价的小额 Cash 替代项。所有彩头须在玩家参赛前说明，不包含强制饮酒、身体接触或公开隐私。

比赛奖惩是**社交机会**，不是直接增减攻略值。例如赢来的特调券让玩家有理由约人去吧台；对方是否愿意同行仍由角色状态决定。输球后坦然自嘲可能比赢了还吸引某个人；对失败者起哄过头也可能让人退开。

## 4. 饮品、Cash 与微醺

Cash 有限，让“自己喝、请谁喝、是否为谁做特调”成为选择，而不是无限刷好感。饮品效果至少分开记录：花费、个人偏好、是否愿意接受、玩家饮酒量。做对口味不保证好感暴涨；被拒绝也不自动是永久惩罚。

玩家可选择真的喝，也可在特定对话中选择“装醉”。微醺可以逐渐影响第一人称视听和操作手感，但须可读、可调节，不让模糊效果妨碍基本游玩。装醉是一种有风险的社交表演：被识破、让对方担心或越过对方边界都可能带来不同后果；**醉意不应成为降低他人同意标准的万能钥匙**。弹球目标杯与饮酒杯分开，命中或末位均不强迫饮酒。

## 5. 角色自主性与“天道”的边界

四位角色需要各自的即时目标、偏好、边界、对玩家的印象，以及对其他三人的关系状态。她们可以主动找人、拒绝邀请、改变位置或提出邀约；玩家不是唯一推动世界的人。但第一版只需少量清楚可见的自主行动，避免玩家站在一旁看四人演一整场自己无法加入的戏。

“天道”在这里先定义为**机会调度层**：工作人员到点组织游戏是酒吧自身的营业安排，不必由“天道”随机发明；调度层只负责在合适的对话间隙落实招呼、赛后独处机会、流星雨提醒或角色主动邀约。它不替角色决定喜欢谁，不强迫特定关系发生，也不生成玩家无法理解的突发事故。先用可检查的规则跑通样板，再讨论更开放的世界预测或自主编排。

角色提示词负责“她是谁、想要什么、怎么表达、什么事会拒绝”；玩法系统负责 Cash、饮酒量、投球结果、地点、时间窗口等客观状态。邀请能否成功应综合角色当晚经历和边界，不只检查一个好感数值。界面至少要让玩家读懂近期态度变化及原因；最终采用数字、阶段标签还是两者结合，留给试玩判断。

## 6. 本晚结算，不等于全游戏终局

结算至少保留四类可达结果：浪漫倾向的同行、朋友同行、独自/旁观上楼、未上楼或提前离场。前两类达成本晚“与人共同看流星雨”的目标；后两类仍给出具体反馈与后续场景选择，不用空白失败页惩罚探索。

若给角色一段内心独白或对玩家的评价，只能依据她实际看见、听见或被告知的事；不能用上帝视角公开别人的隐私。结算可显示今晚与谁更近、谁保持距离、谁提出下次见面。温泉场景目前是候选下一站，开放条件与互动尚未定稿，不在首夜样板中承诺已可游玩。

## 7. 交给技术同学的首轮验收范围

先做一条从入场到结算的可玩链路：一键开局、无必填身份问卷；清楚的开场目标；至少一段可自由选择对象的交流；Cash/饮品的一次有效选择；五人弹球的物理投球与可见输赢；赛后一个由输赢产生的不同互动；流星雨邀请的接受/拒绝与独自上楼分支；本晚结果页。角色先用占位台词或受控回应也可以，但所有投球与选择结果必须真实可追踪。

**暂不纳入首轮：** 完整城市、多场景连续游玩、温泉制作、杀人/警局分支、开放式“天道”生成全夜剧情、四位角色全部最新剧本。它们是后续方向，不该阻挡第一晚是否好玩的验证。

试玩时重点问三件事：玩家进场后是否明白能做什么；弹球是否真的好玩且不拖时间；赛后的赢家/末位互动是否让玩家更想接近某个角色。若这三点不成立，先改玩法节奏，不急着扩写长剧本。

## 8. 下一轮创作待确认

1. 首轮默认不预设玩家与四人的深层旧关系；日后是否开放“原本认识某位角色”的来历？如果开放，必须补写该角色相应的记忆与开场互动。
2. 四位角色最新版的人物设定分别以哪份资料为准？尤其万塞不沿用旧 Demo 的旧设计。
3. 弹球后赢家与末位的三组选项是否合适？需要先通过原型验证投球轮数和一场时长。
4. 玩家看到的“攻略反馈”要多显性：数字好感、阶段标签、角色行为变化，还是组合？
5. 露台之后要先开放哪一个后续场景？温泉可以作为候选，但不预设它是唯一下一站。
