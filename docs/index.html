进入一场已经开始的关系局

玩家没有固定攻略对象，也没有预设正确答案。你可以自由表达、移动和选择行动。四名角色依据各自的记忆、立场与边界继续行动，她们也会彼此影响。

有事件锚点，
没有固定攻略路线。

位置决定谁能听见你的话。在场者形成各自的理解，角色带着这些记忆进入下一次选择。

玩家如何介入

当前 Demo 已呈现玩家身份设定、自然语言输入、社交动作卡、3D 空间移动，以及多角色同场互动。

01

带着自己进入

玩家先设定今晚的身份、状态与边界，它们会成为角色理解你的第一层背景。

02

说话，也做选择

自由输入承载细腻表达，动作卡让靠近、观察、回避与试探成为可见行动。

03

承担关系后果

同一句话会在不同角色心中留下不同印象，后续行为由这些理解共同推动。

多智能体叙事架构

角色拥有自己的理解与选择

每个角色作为独立 Agent 维护自己的记忆、关系判断和行动边界。共享世界负责时间、位置、公共事件和可见性，让角色的反应来自她真正经历过的事情。

A

各自记得什么

角色只记录自己听见、看见或被告知的事件。

B

各自如何理解

同一件事可以形成不同判断，不共享全知视角。

C

各自决定下一步

回应受到人物目标、关系历史与当前边界共同约束。

规划方向

一局结束后，关系可以继续

玩家未来可以授权导出本局的关键记忆，再导入角色 AI。角色延续共同经历、称呼变化与未完成的话题。玩家能够选择导出的内容，也可以随时删除或重置。
