# LaLa-Land · UE 酒吧试玩版

这是一个持续更新的公开试玩入口。当前构建：2026-10-06 / Recording Demo v002 / Windows x64 / UE 5.8.2 Development。

## 下载与启动

下载附件 **LaLaLand-UE-Windows.zip**，完整解压后运行根目录的 **LoungeGameplayIntegration_v001.exe**。不需要安装 Unreal 编辑器。不要单独移动 exe，保留所有文件夹。

首次启动可能需要等待着色器和资源加载。需要支持 DirectX 12 / SM6 的 Windows 电脑；性能和其他电脑兼容性尚未验收。如果提示缺少运行库，请运行包内 Engine/Extras/Redist/en-us/UEPrereqSetup_x64.exe。

## 这一版可以体验什么

- 第一人称探索酒吧空间，观察当前五位角色与场景资产。
- 吧台点单、自调、选择材料、调整比例、载入参考配方。
- 调酒制作演出、成品展示与自饮；每次启动提供 18 Cash 本地试玩预算。
- 新的四款酒瓶资产用于调酒台与背柜展示。

## 操作

WASD 移动，鼠标控制视角；走到吧台客人侧中间，按 E 打开点单/调酒。

在调酒界面用鼠标点击按钮；Enter 确认，Esc 返回，V 切换近景。制作中请等待约 1–4 秒，不要连续确认。

成品完成后按 F 自饮，R 重置本地试玩预算。退出请使用 Alt+F4。

## 重要状态说明

这是**离线调酒与空间展示原型，不是完整游戏**。完整剧情、在线 AI 对话、赠饮同意流程、40 分钟首夜机制、正式存档、投球玩法和完整电梯/楼梯/上层露台动线尚未接入这一试玩构建；角色目前以展示/待机为主。

编辑器下的调酒流程此前通过本地自动检查；**本次独立发行包按作者要求跳过运行试玩，因此独立包运行、性能与兼容性未验证**。打包完成不等于所有玩法验收。

本包不包含 API 密钥，不会主动开启付费生成服务或在线叙事后台。UE 版本仅提供 Windows 构建；之前 Release 的 macOS 包属于旧版，不能代表这一版的 macOS 支持。
